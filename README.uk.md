# Battery Check

[English](README.md) · **Українська**

Монітор батареї та енергоспоживання ноутбука з Windows: куди йдуть вати — за компонентами й програмами — і як зменшити витрату в простої. Windows 10/11, без прав адміністратора, нічого не потрібно встановлювати, крім самої програми.

![Вікно Battery Check: потужність за компонентами за останню хвилину, батарея і сесія розряду](docs/screenshot.png)

## Що вміє

- **Потужність наживо** — загальна витрата з батареї, розкладена на процесор, вбудовану графіку, відеокарту NVIDIA та решту (екран, плата, SSD, Wi-Fi), з графіком від 1 хвилини до 10 годин. Значок у треї показує поточні вати.
- **Програми** — оцінка потужності кожного процесу; які програми не дають заснути відеокарті NVIDIA; що працює, поки ви не за ноутбуком.
- **Батарея** — здоров'я і знос, цикли заряду, залишок часу та чи чесні відсотки заряду Windows (віддана енергія проти спаду відсотків).
- **Історія** — кожен розряд: час від батареї, витрачена енергія, середня потужність, прогноз повного розряду і куди пішла енергія (екран, простій, найбільші програми).
- **Простій** — скільки цей ноутбук споживає, коли нічого не відбувається, і на скільки ватів більше зараз.
- **Журнал пробуджень NVIDIA** — коли прокидалася дискретна відеокарта, на скільки, скільки це коштувало і ймовірна причина.
- **Поради** — конкретні кроки на основі ваших власних вимірів; перевірка **«до / після»** вимірює, чи справді зміна допомогла.
- **Профіль «Від батареї»** — нижча яскравість і частота екрана, режим ефективності для вибраних програм; при підключенні зарядки все повертається.
- **Режими живлення** — ⚡ Standard (нічого не змінюється), 🍃 Eco (без Turbo Boost, енергозбереження, фонові програми в режимі ефективності, програми переводяться з дискретної відеокарти), ❄ Subzero (Eco плюс обмеження процесора та зупинка фонових служб виробника — з вашої згоди через UAC).

Інтерфейс англійською та українською. Детально про кожну функцію — як вимірюється, обмеження, формати логів — у **[повному посібнику](docs/GUIDE.uk.md)**.

**Настільні ПК** (без батареї) теж підтримуються: процесор, вбудована графіка, відеокарта NVIDIA, потужність програм, системний таймер, поради й режими Eco/Subzero. Плитки батареї, історія та вимір екрана приховані, а споживання всього ПК не показується — у настільного ПК немає такого датчика. Спробувати цей режим на ноутбуці: `BatteryCheckGui.exe --no-battery`.

## Встановлення

1. Завантажте `BatteryCheckSetup-<версія>.exe` з [Releases](https://github.com/nik-agilefox/BatteryCheck/releases/latest).
2. Запустіть. Exe не підписаний, тому Windows SmartScreen попередить: **Докладніше → Виконати однаково**.

Програма встановлюється лише для поточного користувача, у `%LOCALAPPDATA%\Programs\BatteryCheck` (логи — у теці `logs`), з ярликом у меню «Пуск» і записом у **Інстальованих програмах** для видалення. Тихий режим: `BatteryCheckSetup.exe /silent`.

**Оновлення.** Кнопка **Check updates** унизу вікна (програма також перевіряє сама — при запуску і раз на 6 годин). Коли виходить новіший реліз, кнопка стає **Update to X**: програма завантажує його, звіряє розмір і SHA-256, замінює свої файли й перезапускається. Логи й налаштування зберігаються.

**Видалення** — через «Інстальовані програми». Якщо ввімкнено Eco або Subzero, спершу перемкніть на Standard: так повернуться налаштування живлення Windows, які змінив режим.

## Приватність

Усе залишається на вашому комп'ютері: виміри пишуться в CSV-файли в теці `logs` і нікуди не надсилаються. Єдиний мережевий запит — перевірка оновлень через GitHub API.

## Збірка з вихідного коду

Використовується компілятор C# з .NET Framework 4.8 — він є в кожній Windows 10/11, більше нічого не потрібно.

```
build.cmd                   зібрати в bin\
test.cmd                    запустити тести
bin\BatteryCheckGui.exe     програма з вікном
bin\BatteryCheck.exe        консольна версія
bin\BatteryCheckSetup.exe   інсталятор (обидва exe всередині)
```

Структура: `src\Core` — виміри, логи й логіка, спільні для обох версій; `src\Gui` — вікно (WPF, без XAML); `src\Console`; `src\Setup` — інсталятор; `tests`; `tools` — допоміжні скрипти. Правила порад і списки виробників — у `src\Core\rules.json`; власні доповнення — у `rules.user.json` у теці програми, поруч із `logs`.

Випуск версії: `powershell -ExecutionPolicy Bypass -File tools\release.ps1 -Version 1.0.1 -Notes "Що змінилося"` — ставить номер версії, запускає тести, збирає і публікує реліз на GitHub з пакетом оновлення та інсталятором.
